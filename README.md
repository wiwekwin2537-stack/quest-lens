# Quest Lens 0.2

แอป Android 14 ขึ้นไปสำหรับบันทึกตัวอย่างการเล่นเควสจากโทรศัพท์เครื่องที่รันเกม ใช้งานได้โดยตรงบนมือถือโดยไม่ต้องเชื่อมโน้ตบุ๊ก

## ดาวน์โหลด APK

[QuestLens-0.2.apk](dist/QuestLens-0.2.apk) เป็น APK รุ่นทดลองสำหรับ Android 14 ขึ้นไป ติดตั้งทับรุ่น 0.1 ที่ดาวน์โหลดจาก repo นี้ได้ ตรวจค่าไฟล์ได้จาก [SHA256SUMS](dist/SHA256SUMS)

## บันทึกและส่งให้ตรวจ

1. เปิด Quest Lens กด **เปิดปุ่มลอย** แล้วอนุญาตการแจ้งเตือนและแสดงทับแอปอื่น กดเปิดอีกครั้งเมื่อกลับจากหน้าตั้งค่า ลากวงกลม QL ไปอยู่มุมที่ไม่บังรายการเควสได้
2. เข้าเกม แตะ **QL → เริ่มบันทึก** แล้วเลือกแอปเกมในหน้าของ Android หากยังอยู่ที่ Quest Lens ให้กลับเข้าเกม เมื่อปุ่มลอยขึ้น **!** แปลว่าแอปที่เลือกยังไม่ปรากฏบนหน้าจอ เลือกแนวนอนหรือแนวตั้งจากหน้า Quest Lens ให้ตรงกับเกมก่อนเริ่ม
3. เปิดสมุดเควส ค้างแต่ละหน้าประมาณ 2 วินาที เลื่อนให้เห็นทุกรายการที่ต้องการ แล้วเปิดหน้ารายละเอียดเควส 100 ให้เห็นชื่อ เงื่อนไขเลเวล สถานะ และปุ่ม หากต้องการระบุหน้าสำคัญให้แตะ **QL → ทำเครื่องหมายหน้าเควส** ขณะหน้านั้นยังเปิดอยู่
4. ลองกดเควสหนึ่งรอบให้เห็นสถานะก่อนและหลัง แบ่งเป็นหลายคลิปถ้าต้องสาธิตเกิน 90 วินาที ถ้ามีตัวละครเลเวลต่างกัน ให้บันทึกแยกและส่ง ZIP แต่ละรอบก่อนบันทึกชุดถัดไป แอปเก็บชุดล่าสุดไว้ชุดเดียว
5. แตะ **QL → หยุดและบันทึกไฟล์** หรือหยุดจากการแจ้งเตือน กลับเข้าแอปแล้วเปิดดูคลิปล่าสุด หากพร้อมส่งให้กด **บันทึก ZIP ลงเครื่อง** เลือก Downloads แล้วกลับมาแนบ `quest-demo-….zip` ในแชต จะใช้ปุ่มแชร์แทนก็ได้

ถ้าเลือกแอปเกมแล้วภาพไม่ติด ให้ติ๊ก **บันทึกทั้งหน้าจอ** ในหน้า Quest Lens แล้วเริ่มใหม่ กลับเข้าเกมทันทีหลังอนุญาตและหยุดก่อนเปิดแอปอื่น โหมดนี้อาจติดภาพแอปอื่นและการแจ้งเตือนด้วย หากวิดีโอสั้นกว่าระยะที่บันทึกมาก แอปจะแจ้งว่า **ภาพขาดช่วง** และเก็บคลิปล่าสุดรอบก่อนหน้าไว้

## แสดงจุดแตะในคลิป

Android มี **ตัวเลือกสำหรับนักพัฒนา → แสดงการแตะ (Show taps)** ควรลองบันทึกสั้น ๆ ก่อน หากคลิปเฉพาะแอปไม่มีวงแตะ ลองเลือก **ทั้งหน้าจอ** เฉพาะช่วงที่เปิดเกม แล้วตรวจคลิปก่อนส่ง โหมดทั้งหน้าจออาจติดหน้าต่างหรือการแจ้งเตือนอื่นด้วย ควรหยุดก่อนออกจากเกม เมื่อสาธิตเสร็จปิด Show taps ได้ตามเดิม

แอปบันทึกวิดีโออย่างเดียวโดยไม่มีเสียงและขออนุญาตบันทึกผ่าน Android ทุกครั้ง ไฟล์อยู่ในพื้นที่ส่วนตัวของแอปจนกว่าจะเลือกส่งออก แอปไม่มีสิทธิ์อินเทอร์เน็ตและไม่ใช้ Accessibility, ADB หรือ root ขณะใช้งาน การป้องกันภาพของ Android และของเกมยังมีผลตามปกติ ถ้าเกมซ่อนปุ่มลอย ใช้หน้า Quest Lens เริ่มบันทึกและหยุดจากการแจ้งเตือน

## เปิดชุดสาธิตในเครื่อง

ชุดสาธิตมี `recording.mp4` และ `session.json` พร้อมเวลาของจุดสำคัญในคลิป สคริปต์ด้านล่างใช้สำหรับผู้ตรวจ ผู้เล่นส่ง ZIP ได้เลย

```sh
python -m pip install "opencv-python-headless>=4.10,<5"
python tools/review_demo.py quest-demo-example.zip review --frame 1.5
```

ถ้าเห็นจุด Show taps ในคลิป เลือกเฟรมตัวอย่างที่เห็นวงชัดบนพื้นเรียบ ใส่เวลาเป็นวินาทีและตำแหน่งกึ่งกลางจุดเป็นพิกเซลของวิดีโอ

```sh
python tools/review_demo.py quest-demo-example.zip review-taps --sample 1.5 120 105 --radius 13
```

ผลมีภาพหน้าที่ทำเครื่องหมายและ `timeline.json` พิกัดที่สคริปต์ได้คือพิกัดบนวิดีโอและอาจมีความคลาดเคลื่อน โดยเฉพาะเมื่อเกมมีเอฟเฟกต์คล้ายวงแตะ การกดเร็วมาก หรือเลือกแชร์แค่หน้าต่างเกม ให้ใช้ภาพก่อนและหลังการกดเพื่อยืนยันชื่อเควสกับผลที่เกิดขึ้นก่อนนำไปกำหนดกติกาบอท

## สร้างแอปจากซอร์ส

เปิดโฟลเดอร์นี้ใน Android Studio ด้วย JDK 17 และ Android SDK 35 จากนั้นซิงก์ Gradle แล้วเลือก Build APKs หากใช้ CLI ให้ใช้ Gradle 8.11.1 และรัน `gradle :app:assembleDebug` APK รุ่นทดลองที่แจกเซ็นด้วยกุญแจทดสอบ ส่วน APK ที่สร้างจากเครื่องอื่นจะใช้ลายเซ็นของเครื่องนั้น
